# unthinkable-solutions

Smart Resume Screener
Project Description

Smart Resume Screener is an AI-powered recruitment application that automates the resume screening process. It allows recruiters to upload resumes in PDF, DOCX, or TXT format and provide a job description. The system extracts important candidate information such as skills, education, and experience and compares it with the job requirements.

Using an LLM, the application performs semantic matching and generates a match score from 1–10. It also identifies matched and missing skills, analyzes strengths and weaknesses, and provides a SHORTLIST, MAYBE, or REJECT recommendation with an AI-generated justification.

Key Features
PDF, DOCX, and TXT resume parsing
Automatic candidate information extraction
Skills, education, and experience extraction
LLM-based resume and job description matching
Match score from 1–10
Matched and missing skills identification
Strengths and weaknesses analysis
SHORTLIST / MAYBE / REJECT recommendation
AI-generated justification
SQLite database for storing candidate information
Separate frontend and backend architecture
Technology Stack

Frontend: HTML, CSS, JavaScript
Backend: Python, FastAPI, Uvicorn
AI/LLM: OpenAI API
Database: SQLite
Resume Processing: PyPDF, python-docx
